ความยินยอมในการเก็บรวบรวม ใช้ และเปิดเผยข้อมูลส่วนบุคคล (Personal Data Consent Form)
🔐 ความเป็นส่วนตัวของข้อมูลส่วนบุคคล

ระบบจะทำการเก็บรวบรวม ใช้ และประมวลผลข้อมูลส่วนบุคคลของท่าน เพื่อวัตถุประสงค์ในการให้บริการด้านการวิเคราะห์และคำแนะนำทางการเงิน โดยข้อมูลที่จัดเก็บประกอบด้วย:

ประเภทข้อมูลที่จัดเก็บ

• LINE User ID

• เลขรหัสพนักงาน

• ข้อมูลส่วนบุคคลอื่น ๆ ที่ท่านกรอกเข้าสู่ระบบ

• ข้อมูลทางการเงินที่เกี่ยวข้องกับสถานะทางการเงิน

วัตถุประสงค์ในการใช้ข้อมูล

• เพื่อวิเคราะห์สถานะทางการเงินของผู้ใช้งาน

• เพื่อจัดทำคำแนะนำทางการเงินเฉพาะบุคคล (Personalized Financial Advice)

• เพื่อติดตามความคืบหน้าทางสถานะทางการเงิน (Financial Progress Tracking)

• เพื่อปรับปรุง พัฒนา และประเมินประสิทธิภาพของระบบ

• เพื่อยกระดับคุณภาพการให้บริการและประโยชน์ที่ผู้ใช้งานจะได้รับ

การจัดเก็บและความปลอดภัยของข้อมูล ข้อมูลจะถูกจัดเก็บในระบบที่มีมาตรการรักษาความปลอดภัยที่เหมาะสม และจำกัดการเข้าถึงเฉพาะผู้ที่เกี่ยวข้องตามหน้าที่

ระยะเวลาการจัดเก็บข้อมูล ข้อมูลส่วนบุคคลจะถูกจัดเก็บตลอดระยะเวลาการใช้งานระบบ และอาจจัดเก็บต่อเนื่อง เพื่อวัตถุประสงค์ด้านการพัฒนาและประเมินประสิทธิภาพของระบบ ตามระยะเวลาที่เหมาะสม

สิทธิของเจ้าของข้อมูล (ตาม PDPA) ท่านมีสิทธิในการ:

• เข้าถึงข้อมูลส่วนบุคคลของตน

• แก้ไขข้อมูลให้ถูกต้อง

• ขอให้ลบหรือทำลายข้อมูล

• ถอนความยินยอมในการใช้ข้อมูล ทั้งนี้ การถอนความยินยอมอาจส่งผลต่อความสามารถในการใช้งานระบบบางส่วน

🔗 หากท่านยังไม่เคยกรอกข้อมูลครั้งแรก กรุณาคลิกที่นี่ https://my-fin-buddy.replit.app -> เพื่อกรอกข้อมูลเริ่มต้นของท่าน (สำหรับการประเมินสถานะทางการเงินเบื้องต้นของคุณ ณ ขณะนี้)

• ลิ้งค์นี้สำหรับการกรอกข้อมูลครั้งแรก หลังจาก "ยินยอมและเริ่มใช้งาน" ลิ้งค์นี้จะไม่ปรากฏขึ้นอีก

• กรณีลืมกรอกหรือต้องการลิ้งค์นี้ใหม่อีกครั้ง โปรดแชทมาในไลน์ "ขอลิ้งค์การกรอกข้อมูลครั้งแรก"
